# Problem Statement

People working with loan data often need answers to questions like how many loans are in default or which state has the highest loan balance, but they may not know how to write SQL queries. Our project solves this problem by building an AI agent that understands questions in plain English, queries a synthetic loan database, and returns answers based on the actual data. This makes it easier and faster to get useful information without depending on a data analyst for every question. However, since financial data is sensitive and incorrect numbers can lead to poor decisions, the agent needs to be accurate and should not be allowed to modify the database. To address this, we added read-only restrictions and a separate verification process that we use during testing to check that the answers are supported by the data and that the database remains unchanged.
